02 · 平台

五大原语，不绑定任何智能体框架。自带模型、自带工具、自带沙箱——运行时、策略与账单都集中在同一处。

运行时才是枯燥的部分，而我们偏偏痴迷于这份枯燥。

01 · 身份

稳定身份，而非会话令牌。

每个智能体都拥有长期有效的身份：可撤销的凭据、有边界的策略，以及不随模型更换而丢失的可迁移记忆层。轮换密钥时无需重新接入智能体。

// stable across model swaps
agent.identity = {
  id: "agent_q7_research",
  policy: "tier-3:read-only",
  memory: halcyon.memory("q7"),
};

03 · 审计

审计日志就该有审计日志的样子。

只追加、密码学链接，可流入你的 SIEM。每一次工具调用、每一条提示词、每一次模型更换、每一笔退款——都集中在法务随时可以取证的一处。

04 · 沙箱

真正的沙箱。

每个任务一个 Firecracker 微虚拟机，110 毫秒启动。

05 · 路由

与模型无关的路由。

始终选用通过你评估的最便宜模型，每晚自动更新。
